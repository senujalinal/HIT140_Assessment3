# HIT140 Assessment 3 FIFA World Cup 2026 Regression

This repository is the shared workspace for Assessment 3 in HIT140 Foundations of Data Science. The project will address Objective 2 by developing two linear regression analyses from the same 104-match FIFA World Cup 2026 source used for Assessment 2.

## Required modelling tasks

- Model 2.1 predicts the goal difference between opposing teams using 104 match-level observations and exactly eight pre-match explanatory variables.
- Model 2.2 predicts one team's goals in a match using 208 team-match observations and exactly eight pre-match explanatory variables.

Variables derived from the outcome or events of the match being predicted will not be used. All wrangling, modelling, evaluation, and visualisation will be completed in Python.
