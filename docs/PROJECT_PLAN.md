## Submission constraints

- Due 15 October 2026 at 14:00 ACST in Darwin.
- One group report in Microsoft Word, no more than four A4 pages, single spaced, 10 point font, including the title, names, and student IDs.
- One repository URL containing every Python file and the assessment dataset.

- One AI Usage Declaration Form signed by all four members, including an acknowledgement, reflection, and conversation URL where applicable.

## Technical acceptance checks

- Model 2.1 contains exactly 104 match rows, one response variable, and exactly eight explanatory variables.
- Model 2.2 contains exactly 208 team-match rows, one response variable, and exactly eight explanatory variables.
- Every explanatory variable passes a documented pre-match availability check.
- Train, validation, and test splits respect match chronology; paired team rows from one match remain in the same split.
- Ordinary least squares is compared with regularised and robust linear alternatives using the same folds and metrics.
- The final discussion reports prediction error, uncertainty, diagnostics, limitations, and a justified recommendation.
