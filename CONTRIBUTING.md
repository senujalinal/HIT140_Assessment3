# Contributing

1. Create a short branch for one defined change.
2. Link the change to an issue or milestone item.
3. Run the full workflow before requesting review.
4. Ask a different member to review changes to data construction, modelling, or interpretation.
5. Update the decision, progress, or contribution log when the change affects those records.
6. Use clear commit messages that describe the completed work.

Do not commit generated caches, local environments, presentation scripts, unsigned forms, Turnitin files, or temporary report exports. Do not backdate commits or use another member's identity.
